# K585 Studio v0.3.5

Nueva estética basada en la referencia de VictusFanControl / Night Light Control:

- Fondo negro, texto blanco y tonos grises neutros.
- Paneles y botones angulares, selección con brillo blanco suave y detalles geométricos discretos.
- Controles de iluminación, frecuencia USB, macros y editores con la misma paleta.
- Icono del teclado en negro, plata y blanco para el EXE, la ventana, la cabecera y el instalador.
- Se conserva el naranja para las teclas reasignadas y el color real del selector RGB.

Esta versión cambia la presentación. No modifica el protocolo USB ni el firmware.
Conserva las funciones y la preparación opcional del firmware experimental de lluvia
de v0.3.3. Instalar Studio no actualiza por sí solo el firmware del teclado.
