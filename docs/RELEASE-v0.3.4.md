# K585 Studio v0.3.4

Estrena el icono del teclado compacto con neón cian elegido por el propietario. Se incluye en el ejecutable, la ventana, la barra de tareas, la cabecera de Studio y el instalador. Los accesos directos utilizan el icono del EXE.

El icono conserva la transparencia y contiene diez tamaños, de 16 a 256 píxeles, para las distintas vistas y escalas de Windows.

Incluye las funciones y la preparación opcional del firmware de lluvia de v0.3.3. Instalar Studio no actualiza el firmware del teclado automáticamente; el preset continúa siendo experimental y la grabación es manual con respaldo previo.
